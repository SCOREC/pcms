# PCMS 0.3 -> 0.4 symbol map, used by tools/migrate-pcms.sh.
# Format: <kind> <old> <new>
#   cmake-option / cmake-target: renamed CMake option or imported target
#     (the old option names still work in 0.4 with a deprecation warning;
#     pcms::core is a deprecated alias of pcms::pcms)
#   macro: renamed preprocessor macro
#   cpp: C++ name that moved to another namespace and is still public;
#     migrate-pcms.sh rewrites it
#   cpp-private: C++ name that moved and is no longer installed; code outside
#     PCMS must use the public replacement (see the manual entries and
#     MIGRATION.md); migrate-pcms.sh only reports it
#   manual: API that changed shape; migrate-pcms.sh reports uses
# A trailing "external" flag skips the entry under --in-tree: PCMS itself
# still defines the old name (the deprecated pcms::core alias; MAX_DIM, the
# MLS kernels' constant, which is unrelated to the renamed macro).
